# Knowledge

Where the games get their useful facts from. A piece belongs here because it can serve a challenge; once written it is locked, and changes need the owner's approval. Research that can serve a challenge is imported from [`research/results/`](../../research/results/README.md) with its source and evidence label. The rules are in [content.md](../../.claude/rules/content.md).
