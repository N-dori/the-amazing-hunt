# Image-analysis challenge ideas

A collection of photo-challenge ideas for The Amazing Shuk, where taking or analysing a photo adds something a typed answer can't. **Ideas, not approved missions:** not every one will be used. Wording is `TODO(copy)` until the owner approves it.

- **Status**, as in [Mission and task ideas](../Mission_Task_Ideas.md): Idea → Shortlisted → Paper-tested → Field-tested → Dropped. Everything starts as Idea.
- **Check type** refers to the table in [run 10b §1](../../../../../research/results/app-tech/10b_photo_answer_verification.md#1-check-fallback-and-unsure-path-by-challenge-type), which gives each type its check, fallback and unsure path. A typed answer is always available ([product decisions](../../../../../docs/project/product-decisions.md), 3 Nov 2026).
- **The test before adding one** ([run 11](../../../../../research/results/app-tech/11_image_analysis_challenge_ideas.md)): would replacing the camera with a multiple-choice question lose something? If not, it belongs in the main ideas bank as a typed or found answer.
- **Add freely.** Note where the idea came from.
